# Vehicle Maintenance Prediction System — Flask Backend

> **Synthetic-data notice:** This project uses a *synthetic* dataset that was
> generated programmatically for educational and demonstration purposes.  It
> does not represent real vehicle histories.  The model and its evaluation
> metrics are **not** validated for real-world maintenance decisions.  Do not
> use predictions from this system as a substitute for professional vehicle
> inspection.

---

## Project Overview

A Python Flask REST API that predicts whether a vehicle is likely to need
maintenance within the next 30 days.  The prediction is produced by a
`RandomForestClassifier` trained on synthetic vehicle data.

This is a college-level data science project demonstrating:
- scikit-learn Pipelines with preprocessing (imputation + one-hot encoding)
- Model evaluation against a `DummyClassifier` baseline
- Flask REST API design with structured input validation
- Persisting models with Joblib and evaluation reports as JSON

## Training the Model

Run the training script once before starting the API:

```cmd
python train_model.py
```

This will:
1. Load and validate `data/vehicle_maintenance_synthetic.csv`
2. Perform a stratified 80/20 train-test split (`random_state=42`)
3. Fit the preprocessing pipeline **only on the training data**
4. Train a `RandomForestClassifier(random_state=42, class_weight="balanced")`
5. Compare it with a `DummyClassifier` baseline
6. Save evaluation metrics to `reports/metrics.json`
7. Save a labeled confusion-matrix heatmap to `reports/confusion_matrix.png`
8. Save the fitted pipeline to `models/maintenance_pipeline.joblib`

The model is **never** trained automatically when Flask starts or when a
request arrives.

## API Endpoints

### GET /api/health

Returns API status and whether a trained model is loaded.

```json
{
  "status": "ok",
  "model_loaded": true,
  "message": "Model is ready for predictions."
}
```

### GET /api/model-info

Returns model metadata, accepted input values, and evaluation metrics from
`reports/metrics.json`.

### POST /api/predict

Accepts one vehicle record and returns a prediction.

**Required JSON fields:**

| Field                    | Type    | Constraints                                      |
|--------------------------|---------|--------------------------------------------------|
| `Vehicle_Age_Years`      | number  | > 0                                              |
| `Fuel_Type`              | string  | `"Petrol"` or `"Diesel"`                         |
| `Odometer_Km`            | number  | ≥ 0                                              |
| `Average_Daily_Km`       | number  | ≥ 0                                              |
| `Days_Since_Last_Service`| integer | ≥ 0, ≤ Vehicle_Age_Years × 365                  |
| `Km_Since_Last_Service`  | number  | ≥ 0, ≤ Odometer_Km                               |
| `Previous_Repairs_Count` | integer | ≥ 0                                              |
| `Driving_Condition`      | string  | `"City"`, `"Highway"`, `"Mixed"`, or `"Rough"`   |

**Example request body:**

```json
{
  "Vehicle_Age_Years": 6,
  "Fuel_Type": "Diesel",
  "Odometer_Km": 90000,
  "Average_Daily_Km": 45,
  "Days_Since_Last_Service": 210,
  "Km_Since_Last_Service": 9500,
  "Previous_Repairs_Count": 3,
  "Driving_Condition": "City"
}
```

**Example response:**

```json
{
  "prediction": 1,
  "maintenance_needed": true,
  "maintenance_probability": 0.7342,
  "message": "Maintenance is predicted within the next 30 days (model probability estimate: 73.4%).  Consider scheduling a service inspection.",
  "data_notice": "Model trained on synthetic data; for educational demonstration."
}
```

`maintenance_probability` is the model's raw estimated probability for class 1
(maintenance needed).  It is **not** a calibrated real-world risk figure.

## Preprocessing Details

The scikit-learn Pipeline applies the following steps, fitted **only on
training data**:

| Step                       | Applied to                              |
|----------------------------|-----------------------------------------|
| Median imputation          | All six numeric features                |
| Most-frequent imputation   | `Fuel_Type`, `Driving_Condition`        |
| One-hot encoding           | `Fuel_Type`, `Driving_Condition`        |
| RandomForestClassifier     | All transformed features                |

`handle_unknown="ignore"` is set on the encoder so unseen category labels
at prediction time do not cause errors.

---

## Evaluation Metrics

Metrics are written to `reports/metrics.json` after training.  Both the
`RandomForestClassifier` and the `DummyClassifier` baseline are evaluated on
the held-out 20 % test split using:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- Confusion Matrix

Because the dataset is **synthetic**, these numbers reflect in-sample
generalisation on artificial data only and should not be interpreted as
real-world predictive performance.

## Error Responses

|-----------|-----------------------------------------|
| 400       | Validation failure (field-level errors) |
| 404       | Unknown endpoint                        |
| 503       | Trained model file not found            |
| 500       | Unexpected server error (safe JSON)     |

Stack traces are never exposed in API responses.

## Limitations

- Dataset is **synthetic** — results do not generalise to real vehicles.
- No authentication, rate limiting, or database integration (out of scope).
- The model is loaded into memory at startup; a process restart is needed
  after retraining.
